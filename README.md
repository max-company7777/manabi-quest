# まなびクエスト

もんだいを といて モンスターを たおす、子供向けの学習ゲーム（PWA）。
さんすう・えいご・こくご（ひらがな／漢字）を、ハクスラ要素で楽しく続けられます。

## 遊び方
- スマホ・タブレットのブラウザでこのサイトを開く
- 「ホーム画面に追加」すると、アプリのように起動できます（一度開けばオフラインでも遊べます）

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体 |
| `manifest.webmanifest` | アプリ名・アイコンなどの設定 |
| `sw.js` | オフラインで遊べるようにする仕組み（Service Worker） |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アプリのアイコン |

## 公開のしかた（GitHub Pages・無料）
1. GitHub で **Public** のリポジトリを作る（例：`manabi-quest`）
2. 上のファイルをすべてアップロード（Add file → Upload files → Commit changes）
3. Settings → Pages → Build and deployment の Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
4. 1〜2分で `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります

## 更新のしかた
- 新しい `index.html` を同じ名前でアップロード（上書き）して Commit するだけです
- `sw.js` を書き換える必要はありません。次にネットにつながった状態で開いたときに、自動で新しい版になります
  - 開きっぱなしの場合は、一度アプリを閉じて開き直してください

## セーブデータについて
- セーブデータは各端末（ブラウザ）の中だけに保存されます。サーバーには送られません
- 別の場所・別の端末へ移すときは、ゲーム内の「⚙️ せってい → 💾 データの ひっこし」で
  「かきだす」→ 表示されたコードを移動先で「よみこむ」
- iPhone/iPad では、ホーム画面のアイコンから開いた場合と Safari から開いた場合でデータが別になります。いつも同じ方法で開いてください
